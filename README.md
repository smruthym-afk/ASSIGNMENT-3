# ASSIGNMENT-3 HEALTHCARE DATA ANALYSIS DASHBOARD
This project analyses healthcare data using Microsoft Excel to identify patterns in patient health conditions, hospitalisation and healthcare charges.
The project uses data cleaning, data analysis, PivotTables, PivotCharts, and an interactive dashboard to identify patterns and compare healthcare outcomes.
# Objectives
Analyse cancer history among smokers and non-smokers.

Examine major surgeries and average HbA1C levels based on transplant history.

Compare average healthcare charges by weight status and diabetes status.

Analyse average healthcare charges across hospital tiers and states.

Identify correlations between age and BMI, and age and HbA1C.

Explore the relationship between age and healthcare charges.

Build an interactive dashboard to support comparisons using slicers.

# Data Preparation and Cleaning

The project involved combining information from multiple healthcare datasets, including:

1.Customer Names

2.Medical Examinations

3.Hospitalisation Details

The datasets were combined into a consolidated Healthcare worksheet using customer IDs.

# Data preparation included:

Combining datasets using lookup formulas.

Handling missing or unknown values.

Replacing missing State ID values (?) with Unknown.

Calculating patient age from date of birth.

Categorising patients by weight status using BMI.

Categorising diabetes status using HbA1C values.

# Analysis and Visualisations

1. Cancer History Analysis

    Analysed the distribution of cancer history among smokers and non-smokers using a PivotTable and chart.

2. Transplant History Analysis

    Compared total major surgeries and average HbA1C levels between patients with and without transplant history.

    Key findings:

    Patients without transplant history: 1,417 major surgeries and average HbA1C of 6.67.

    Patients with transplant history: 162 major surgeries and average HbA1C of 5.19.

3. Weight Status and Diabetes Analysis

    Compared average healthcare charges across different weight categories and diabetes conditions.

4. Hospital Tier Analysis

    Examined average healthcare charges by hospital tier across different states.

5. Age, BMI and HbA1C Analysis

    Used scatter plots to explore the relationships between:

    Age and BMI.

    Age and HbA1C.

6. Age and Healthcare Charges

    Created a scatter plot to examine the relationship between patient age and healthcare charges.

# Interactive Slicers

Two slicers were added:

Weight Status – Normal Weight, Overweight, Obesity and Underweight.

Diabetes Status – Normal, Prediabetes and Diabetes.

These slicers allow users to filter connected PivotTables and PivotCharts and compare healthcare charges and relevant health indicators across patient categories.

# Key Insights

Patients without transplant history had a higher total number of major surgeries in this dataset.

Average HbA1C differed between patients with and without transplant history.

Healthcare charges can be compared across weight and diabetes categories.

Hospital tier and state provide additional dimensions for examining healthcare costs.

Scatter plots help explore possible relationships between age, BMI, HbA1C and healthcare charges.

# Conclusion

This project demonstrates how Microsoft Excel can be used to transform healthcare data into meaningful insights through data cleaning, analysis, PivotTables, charts and interactive dashboards.

The dashboard provides a convenient way to explore healthcare patterns and compare patient groups based on weight status and diabetes condition.
